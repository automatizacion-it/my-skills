# SKILL: Redactar Email Profesional

## Propósito
Redactar emails profesionales en español con tono adecuado, estructura clara
y llamada a la acción precisa.

## Cuándo usar esta skill
- Seguimiento a propuestas o cotizaciones
- Comunicación con clientes o proveedores
- Notificaciones internas formales
- Respuestas a reclamos o solicitudes

## Instrucciones

### Paso 1 — Analiza el contexto
Antes de escribir, identifica:
- **Destinatario**: ¿cliente, proveedor, colega interno?
- **Objetivo**: ¿informar, pedir, confirmar, agradecer?
- **Tono**: ¿formal, semi-formal, cercano?

### Paso 2 — Estructura obligatoria
Todo email debe tener:
1. **Saludo** personalizado (usa el nombre si está disponible)
2. **Contexto breve** (1-2 oraciones: de qué trata el email)
3. **Cuerpo principal** (máximo 3 párrafos cortos)
4. **Llamada a la acción** clara y específica
5. **Cierre** cordial + firma

### Paso 3 — Reglas de estilo
- Párrafos de máximo 3 oraciones
- Evitar jerga técnica salvo que el destinatario la maneje
- No usar más de una llamada a la acción
- Tono siempre respetuoso, nunca pasivo-agresivo
- Si hay urgencia, mencionarla en el primer párrafo, no al final

## Restricciones
- NO inventar datos, fechas o nombres que no estén en el input
- NO incluir emojis en emails formales
- NO exceder 200 palabras salvo que el usuario lo pida explícitamente

## Output esperado
```
Asunto: [asunto claro y específico]

[Saludo],

[Cuerpo del email]

[Cierre],
[Firma]
```

## Ejemplos

### Input
"Escribe un email a Laura Gómez recordándole que su propuesta vence el viernes"

### Output esperado
```
Asunto: Recordatorio — Propuesta pendiente de aprobación

Estimada Laura,

Espero que se encuentre bien. Le escribo para recordarle que la propuesta
que le enviamos el pasado lunes tiene fecha límite de respuesta el próximo
viernes 2 de mayo.

Si tiene alguna pregunta o requiere información adicional para tomar su
decisión, con gusto la atendemos antes de esa fecha.

Quedo pendiente de su respuesta.

Atentamente,
[Tu nombre]
```
